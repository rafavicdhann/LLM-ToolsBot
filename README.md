# 🤖 ToolFinder AI - Digital & AI Tools Finder Chatbot

ToolFinder AI adalah aplikasi chatbot interaktif berbasis LLM (Google Gemini) yang dibangun menggunakan Streamlit. Chatbot ini dirancang untuk mendiagnosis kebutuhan pengguna dan memberikan 3 hingga 5 rekomendasi software, aplikasi, atau AI tools terbaik secara terstruktur, relevan, dan akurat.

Proyek ini dibuat untuk memenuhi tugas **Final Project AI Chatbot**.

---

## 🌟 Fitur Utama
- **Rekomendasi Terstruktur:** Menampilkan 3–5 opsi tools lengkap dengan skema harga, fitur unggulan, dan *Top Pick*.
- **Persona Konsultan:** Dikonfigurasi dengan System Prompt khusus sebagai spesialis teknologi yang solutif.
- **Multi-turn Memory:** Mengingat riwayat percakapan pengguna selama sesi berjalan.
- **User Interface Responsif:** Memanfaatkan komponen *chat native* dari Streamlit untuk pengalaman penggunaan yang cepat.

---

## 🛠️ Tech Stack
- **Bahasa Pemrograman:** Python 3.10+
- **UI Framework:** Streamlit
- **LLM Engine:** Google Gemini API (`gemini-1.5-flash`)
- **Environment Manager:** Virtual Environment (`venv`)
